# Навигатор по программе G8 как инструмент афиши

`g8-2026.html` — один самодостаточный файл: вся программа зашита внутрь, внешних
запросов нет, кроме шрифтов Google. Личный план хранится в `localStorage` браузера.

## Что уже готово к афише

- **Ссылки на профили.** В карточке события имена спикеров, которые есть в графе
  сущностей афиши, ведут на `/speaker/<slug>` — 28 из 166 человек, у 11 есть
  готовый профиль, они помечены плашкой «профиль в афише». Слаги посчитаны
  алгоритмом `slugifyEntityKey` из `apps/calendar-web/src/app/utils/slugify.ts`,
  так что ссылки совпадают с существующими страницами. Остальные имена
  оставлены текстом — вести на пустую страницу сущности незачем.
- **Поведение ссылок по домену.** На `design-events.fun` переходы идут в той же
  вкладке, снаружи — в новой (`target="_blank"`).
- Список ссылок пересобирается: `python3 tools/export_for_afisha.py <клон-афиши>`
  обновляет `data/afisha-links.json`, дальше `python3 build.py`.

## Как прицепить

### 1. Статикой (быстро, без сборки)

Положить файл в `apps/public-site/g8-2026.html` и добавить в `vercel.json`:

```json
{"src": "apps/public-site/g8-2026.html", "use": "@vercel/static"}
```

и маршрут **выше** общего `{"src": "/(.*)", "dest": "/index.html"}`:

```json
{"src": "/tools/g8-2026", "dest": "/apps/public-site/g8-2026.html"}
```

Инструмент открывается на `/tools/g8-2026` со своим оформлением — фирстилем G8,
а не дизайн-системой афиши.

### 2. Прицепить к событию

На странице события G8 (`/event/<eventId>`, рендерит
`services/vercel-api/event-page.js`) добавить ссылку «Программа и личный план»
на `/tools/g8-2026`. Обратная ссылка из инструмента настраивается в одном месте —
константа `AFISHA_SITE` в начале скрипта, рядом можно положить и адрес события.

### 3. Внутри витрины (если инструмент приживётся)

Перенести в `apps/calendar-web` как страницу с маршрутом `/tools/g8-2026`:
навигатор получит шапку и стили афиши, ссылки на профили пойдут через
`react-router` без перезагрузки, а личный план можно будет хранить не в
`localStorage`, а в аккаунте — через тот же механизм, что и пользовательские
списки событий. Это уже работа по переносу вёрстки, а не копирование файла.

## Ограничения

- Время окончания события выводится по началу следующего в том же зале;
  у последнего события зала его в программе нет.
- Текст снят с полос-картинок вручную: время и залы выверены, в фамилиях
  и должностях возможны единичные опечатки.
