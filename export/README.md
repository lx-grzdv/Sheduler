# Программа G8 2026 — выгрузка для дизайн-афиши

Данные разобраны из официальной программы фестиваля (`G8_2026_PROGRAM.pdf`, 16 полос
без текстового слоя) и приведены к формату `lx-grzdv/design-events`.

Собирается командой:

```
python3 tools/export_for_afisha.py [путь-до-клона-design-events]
```

Скрипт заодно сверяется с афишей и проставляет флаги совпадений, поэтому пересобирать
выгрузку имеет смысл после обновления графа сущностей.

## Файлы

| Файл | Что внутри |
|---|---|
| `g8-2026-afisha.json` | всё вместе: залы, треки, 128 сессий, 166 спикеров |
| `g8-2026-sessions.csv` | 128 сессий построчно |
| `g8-2026-speakers.csv` | 166 спикеров со слагами и флагами совпадения |

## Ключи и слаги

Слаги посчитаны **тем же алгоритмом**, что и в афише —
`apps/calendar-web/src/app/utils/slugify.ts · slugifyEntityKey` (контекстное «й»,
кириллица → латиница). Поэтому `profile_url` ведёт ровно на существующую страницу,
если человек уже в графе: `Андрей Тубольцев → /speaker/andrei-tuboltsev`.

- `speaker_keys` — сырые ключи в нижнем регистре, как в `eventEntityMap.ts`
  (`{speakerIds:["митя осадчук"]}`), чтобы связи легли без переименований.
- `venue_key` — `хлебозавод №9` (уже есть в `ENTITY_GROUPS`) или `дизайн-завод`.
- `organizer_key` — `g8`, тоже уже встречается в графе.

## Поля сессии

`session_id` (`g8-2026-e011`), `date`, `start`, `end`, `hall` (зал фестиваля),
`venue_key`, `place` (площадка), `track` (секция), `track_curator`, `kind`
(`talk` / `disc` / `special` / `service`), `title`, `speaker_keys`, `speaker_slugs`,
`organizer_key`.

Время окончания выведено по началу следующего события в том же зале; у последнего
события зала его нет — в программе оно не указано.

## Оговорка

Текст снят с полос-картинок глазами, а не OCR: время и залы выверены, но
в написании фамилий и должностей возможны единичные опечатки.
