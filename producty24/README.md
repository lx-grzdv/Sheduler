# Куда пойти на Продукты 24

Расписание и планировщик для конференции «Продукты 24 × ffdd2d» (Т-Банк,
12 сентября 2026, пространство «Мечта» на набережной Парка Горького).
Сделано по образцу расписания G8: три вида, личный план, экспорт.

Один файл — `index.html`. Публикуется как Artifact с возможностями
`{db: {}, downloads: true}`: план хранится в базе артефакта (и дублируется в
localStorage), PDF уходит в системное меню сохранения.

## Что умеет

- **Сетка залов** — столбцы-залы, вертикаль-время, линия «сейчас» в день конференции.
- **Списком** — события по таймслотам, карточками.
- **Мой план** — отмеченное звёздочкой выстраивается по времени; подсвечиваются
  накладки (пересечение по времени), перебежки между залами встык и окна от 40 минут.
- Поиск по теме, спикеру и компании; фильтры по залам и секциям; переключатель перерывов.
- Экспорт плана: PNG и многостраничный PDF (A4), плюс копирование текстом.

## Где живёт программа

Весь контент — в объекте `DATA` в начале `<script>`. Границы дня (`T0`/`T1`),
счётчики в шапке, бегущая строка, легенда цветов и список секций считаются из него,
так что руками их править не нужно.

```js
const DATA = {
  conf: {
    name, edition, date: "2026-09-12", dateLabel, site, organizer, tagline,
    places: [{name, note}],
    dayWindow: "10:00–18:00",
    extras: [{label: "Афтерпати", time: "18:00", place: "…"}]   // стендап, афтерпати и пр.
  },
  venues:   [{id, name, place, color?, colorDark?}],  // цвет можно не задавать — возьмётся из PALETTE
  sections: [{name, curator, venue}],                 // если секций нет, оставить []
  events:   [{
    id: "e001",
    venue: "<id зала>",
    section: "<имя секции|null>",
    curator: "<имя|null>",
    start: "10:00", end: "10:30",
    startMin: 600, endMin: 630,                       // минуты от полуночи, по ним строится сетка
    title: "Название доклада",
    kind: "talk" | "disc" | "break" | "special" | "service",
    speakers: [{name: "Имя Фамилия", role: "должность, компания"}]
  }]
};
```

`kind` влияет на вид: `break` — штриховка и не попадает в план, `disc` и `special`
получают плашку, `service` (регистрация, открытие) не считается в счётчике событий.

Пока `events` пуст, страница честно показывает состояние «программа ещё не
загружена» — остальные механики при этом уже работают.
