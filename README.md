# Расписания конференций

Сайт с расписаниями и планировщиками конференций: сетка залов, поиск по спикерам
и личный план, который предупреждает о накладках и перебежках между залами.

Опубликован на GitHub Pages: **https://lx-grzdv.github.io/Sheduler/**

| Адрес | Расписание |
|---|---|
| `/` | указатель на оба расписания |
| `/producty24/` | «Продукты 24 × ffdd2d», 12 сентября 2026, комплекс «Мечта» |
| `/g8/` | G8 «Креофудкорт», 11 сентября 2026, Хлебозавод и Дизайн-завод |

## Устройство репозитория

```
src/producty24.html   исходник расписания Продуктов 24
src/g8.html           исходник расписания G8
src/build_data.py     пересобирает программу Продуктов 24 в src/producty24.html
build_site.py         собирает сайт: / , /producty24/ , /g8/
```

Исходники написаны как тело артефакта claude.ai: doctype, charset и базовый сброс
стилей добавляет сама площадка. `build_site.py` дописывает эту обёртку — мета-теги,
og-превью, фавиконку — и раскладывает страницы по адресам. Собранные `index.html`
коммитятся, потому что Pages отдаёт их напрямую, без сборки на своей стороне.

Пересобрать сайт после правок:

```
python3 build_site.py
```

Рядом с корнем лежит пустой `.nojekyll`: без него Pages прогоняет файлы через
Jekyll и отдаёт отрендеренный README вместо страницы.

## Где живёт программа

Вся программа Продуктов 24 — в объекте `DATA` в начале `<script>` в
`src/producty24.html`. Границы дня, счётчики в шапке, бегущая строка, легенда
цветов и фильтры считаются из него, руками их править не нужно.

```js
const DATA = {
  conf: {
    name, edition, date: "2026-09-12", dateLabel, site, organizer, tagline,
    places: [{name, note}], dayWindow,
    extras: [{label: "Регистрация участников", time: "с 12:30", place: ""}]
  },
  audiences: [{id: "prod", label: "продактам"}, …],   // фильтр «для кого»
  venues:    [{id, name, hall, hosts: [{name, role}]}],
  events:    [{
    id, venue, start: "14:00", end: "14:30",
    startMin: 840, endMin: 870,                       // минуты от полуночи
    title, kind: "talk" | "disc" | "break" | "special" | "service",
    speakers: [{name, role}],
    about,                                            // описание доклада
    points: [],                                       // «о чём поговорим»
    quote, tags: ["prod"], badge: "только офлайн"
  }]
};
```

Программа собирается скриптом, а не правится вручную:

```
python3 src/build_data.py      # перезаписывает блок DATA в src/producty24.html
python3 build_site.py          # пересобирает страницы сайта
```

## Поведение вне claude.ai

На claude.ai страница получает доступ к базе артефакта и системному сохранению
файлов. На GitHub Pages `window.claude` отсутствует, и страница честно
деградирует: план хранится в `localStorage` браузера вместо общей базы,
а PNG и PDF сохраняются обычной ссылкой со скачиванием.

Наружу уходят только шрифты Google Fonts и — лениво, при экспорте в PDF —
jsPDF с cdnjs. Обе площадки доступны из России.
