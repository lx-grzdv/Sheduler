# Куда пойти на G8

Интерактивный навигатор по программе фестиваля креативных индустрий **G8 «Креативный фудкорт»**
(11 сентября 2026, Хлебозавод + Дизайн-завод, Москва).

Официальная программа существует только как PDF из 16 страниц-плакатов: это картинки,
в них нет текстового слоя, залы разложены по отдельным разворотам, а сравнить, что идёт
в одно и то же время в семи залах, невозможно. Здесь то же расписание, но пригодное
для выбора: сетка залов по времени, поиск, фильтры и личный план.

## Что внутри

- `data/program.json` — расписание в структурированном виде: 156 пунктов (128 содержательных
  событий + перерывы), 7 залов, 22 секции, спикеры с должностями. Время окончания каждого
  события вычисляется по началу следующего в том же зале.
- `src/app.template.html` — одностраничное приложение (без зависимостей, только Google Fonts).
- `build.py` — подставляет JSON в шаблон и собирает `index.html`.
- `index.html` — собранный файл, он же опубликован как артефакт.

## Возможности

- **Сетка залов** — семь колонок, вертикаль времени, видно все параллельные события сразу;
  в день фестиваля показывается линия текущего времени.
- **Списком** — всё расписание по времени с фильтрами по залу и секции и поиском
  по спикерам, темам и агентствам.
- **Мой план** — отмеченные звёздочкой события по порядку, с предупреждениями о накладках,
  о переходах между Хлебозаводом и Дизайн-заводом и о длинных окнах. Экспорт текстом.
- План хранится в `localStorage`, а при публикации артефакта — в общем хранилище
  (`db`-capability), поэтому он подхватывается на другом устройстве.

## Сборка

```
python3 build.py
```

## Источник данных

`G8_2026_PROGRAM.pdf` — официальная программа фестиваля (g8.art). Страницы отрисованы
в PNG и расшифрованы вручную: текстового слоя в PDF нет. Организаторы могут менять
программу — на месте стоит сверяться с официальным расписанием.
